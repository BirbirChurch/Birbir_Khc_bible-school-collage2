# የብርብር ከተማ ቃለ ሕይወት ቤተ ክርስቲያን መጽሐፍ ቅዱስ ትምህርት ቤት - የመረጃ ማኔጅመንት ሲስተም
## Birbir Town Kale Heywet Church Bible School - Student Information & Academic Management System (Android)

ይህ መተግበሪያ ለብርብር ከተማ ቃለ ሕይወት ቤተ ክርስቲያን መጽሐፍ ቅዱስ ትምህርት ቤት የተዘጋጀ ዘመናዊ የ Android መተግበሪያ (Kotlin & Jetpack Compose) ነው።

### ዋና ዋና ባህሪያትና ክፍሎች (Core Features & Portals):

1. **ዋና አድሚን ቁጥጥር ማዕከል (Super Admin Portal)**
   - የሲስተም ጥገና ሁነታ መቆጣጠሪያ (Maintenance Mode Lock)
   - የውጤት ይፋ ማድረጊያ መቆጣጠሪያ (Grade Publication Toggle)
   - የመምህራን መለያ ማኔጅመንት (አዲስ መምህር መመዝገብ፣ መቆለፍ/መክፈት፣ መሰረዝ እና ልዩ ቁልፍ መስጠት)
   - የይለፍ ቃል መቀየሪያ (Change Passwords)
   - ይፋዊ የዲንና ሪጅስተራል ፊርማና ማህተም ማስተካከያ (Official Signatures & Stamp Configuration)
   - የአድሚን ሁለንተናዊ እይታ መቀየሪያ (Universal View Switcher)

2. **የዋና ዲን ፖርታል (Academic Dean Portal)**
   - የስርዓተ-ትምህርትና ኮርሶች መርሃ-ግብር (Curriculum Schedule for Degree & Diploma)
   - የዲን ስምና ማዕረግ ማስተካከያ
   - የውጤት ይፋዊ ሁኔታ ኦዲትና ፍተሻ

3. **የሪጅስተራል ፖርታል (Registrar Portal)**
   - የተማሪዎች ምዝገባ (Add, Edit, Delete Student)
   - የትምህርት ዘመንና ሴሚስተር ማኔጅመንት (Academic Calendar)
   - የተማሪዎች ይፋዊ ትራንስክሪፕት መስጫ

4. **የመምህራን ፖርታል (Teacher Portal)**
   - ልዩ የመምህራን መግቢያ ቁልፍ (Teacher Key e.g. BK-SOL-2019)
   - የተመደቡ ኮርሶችን መምረጥ
   - የተማሪዎች የክፍልና ፈተና ውጤት ማስገቢያ (ክፍል 1፡ 20፣ ክፍል 2፡ 20፣ ሚድ፡ 30፣ ፋይናል፡ 20፣ ተሳትፎ፡ 10)
   - የቀጥታ ድምርና የደረጃ ስሌት (A+, A, A-, B+, B, B-, C+, C, C-, D+, D, D-, F)

5. **የተማሪ የግል ገጽ (Student Portal)**
   - የተማሪ መገለጫ (ስም፣ መለያ ቁጥር፣ ፕሮግራም፣ ፆታ)
   - የሴሚስተር ውጤት ዝርዝርና የውጤት አማካይ (GPA)
   - ይፋዊ ትራንስክሪፕት ቅድመ-እይታ (Official Transcript View)

6. **ይፋዊ ትራንስክሪፕት (Official Transcript)**
   - የቤተ ክርስቲያኑ አርማና ርዕስ
   - የተማሪ ሙሉ ዝርዝርና የኮርሶች ሰንጠረዥ
   - ጠቅላላ ክሬዲትና GPA ስሌት
   - የሪጅስተራልና ዋና ዲን ፊርማና ኦፊሴላዊ ማህተም

### የቴክኖሎጂ ዝርዝር (Tech Stack):
- **Language**: Kotlin 2.0
- **UI Framework**: Jetpack Compose (Material 3)
- **Architecture**: MVVM (Model-View-ViewModel) with StateFlow
- **Design System**: Ethiopian Kale Heywet Church Emerald (#064E3B) and Amber Gold (#F59E0B) palette
- **Icon**: Custom Adaptive Launcher Icon
